# 风险与验证缺口

核验日期：2026-10-09；本轮核对公共图源接口、用途限制及运行期间每日任务。其他条目沿用此前证据，不代表重新审计生产环境。当前状态统一见 [NOW](NOW.md)。

## R01 图源用途与接口稳定性

证据：[接口核验](../../research/source-api-evidence-2026-10-09.json) 保存本轮官方资料与实际API检查入口；[方案§6](../Windows壁纸软件-详细开发方案.html#source) 保留完整选源规划。

缺口：Bing为社区接口，发布用途及长期稳定性未保证；Wallhaven/Commons本机真实连接通过不代表其他地区或持续可用。Commons各图片许可不同，Wallhaven搜索不提供作者；不能将API可用推断为所有图片可再分发。Unsplash本轮官方规则明确排除壁纸API用途，仅提供官网入口；Pexels本轮未重核，未接入。其他截图中的聚合来源没有确立可用API。

保护：保留本地闭环、每张图片的来源与可得署名/许可；Wallhaven仅SFW，限制下载体积和预览等待，所有图片网络地址经过现有HTTPS/公网及重定向检查。适配器错误可重试，不将未核实图源展示为已接通。公开发布前另行核实用途与授权。

本次首页联调曾遇Commons原图TLS握手连接中断；最终接口检查成功不保证持续可用。公网HTTPS GET连接异常最多延迟350ms重试一次，不关闭证书/TLS或公网限制，不重试HTTP限流响应。首页请求有超时/取消与旧图保留，不以历史图片假冒当前Bing每日图；失败不写入成功检查日。

Bing历史图使用第三方社区存档，既有Bing近期接口不能覆盖历史图库。存档代码许可不包含图片再分发许可；CN可用起止日期、响应大小与原图证据见接口核验。仅缓存有大小上限的元数据，随机浏览一次获取一张原图；下载失败保留当前图。图库模式没有可用独立缩略图时显示占位，点击后获取原图。长期存档完整性、未来元数据增长超过限制及地区可用性待核实。

## R07 每日任务与系统能力

证据：[调度](../../src/Stillframe.Core/DailyAutomation.cs)、[Windows调用](../../src/Stillframe.App/Services/PersonalizationService.cs) 和本轮官方接口核验。默认关闭，仅运行期间每分钟检查；各动作成功日期持久化，失败15分钟后重试。

缺口：本机锁屏/通知能力探测为true，尚无实际设置锁屏、显示通知或桌面更换的通过证据。系统通知关闭、普通权限限制、组织个性化策略和多屏部分失败可能阻止效果；多个动作不构成原子事务，先完成的动作不会因后续失败自动回滚。通知接收不等于用户已看到；桌面恢复不覆盖锁屏。

保护：系统返回失败不记作完成；锁屏使用应用专用新文件名，不改源文件或系统策略。关闭软件停止定时器，不安装后台服务。实际系统效果和恢复路径在专用环境或用户授权下另行验收。

## R06 页面重绘与图库导航

证据：用户反馈图库闪退；应用诊断堆栈定位到RenderDetail→Row→UIElementCollection.Add，COMException 0x800F1000。旧实现复用ComboBox，在重新挂载时触发父容器异常。

保护：只保留显示器/适配选择值，每次详情创建新控件；导航异常记录到数据目录navigation-error.txt并提示。回归检查覆盖重复进入详情和收藏后重绘；当前执行结果和证据入口统一见 [NOW](NOW.md#验证状态)。

保护补充：旧抽屉在关闭后Visibility.Collapsed，复开时等待关闭并重建Pane；用户再次指出过渡问题。现改为常驻SplitView原生开关，支持快速反向，不拆除Pane；关闭完成后释放命中测试，避免透明层挡住图片。异步页面依赖在清屏前准备，版本号保护最新导航；相同原图源复用，背景不做整图淡入。窗口缩小后的复开、快速开关、原生快捷换图和重复导航已纳入回归，实际结果见NOW。图片填充可能裁切，提供完整预览切换，原字节导出不受影响。

侧栏点击缺陷：应用自身startup-error.txt记录InvalidCastException，定位到ShowNavigationDrawer的ItemClick处理；旧代码将返回的StackPanel强制转为ListViewItem。该日志文件名不表示异常发生在启动阶段。现在改用DrawerLink数据项，并保护异步事件异常。前次23项回归覆盖页面导航及横杠按钮，但未覆盖侧栏各行的真实点击链路；本轮新增五入口控件调用及紧凑宽度检查，结果统一见NOW。

首页加载保护：原全局进度层移到图片区域或当前页面；旧原图保持到新图完成解码。取消旧请求并校验最新版本，避免快速切源被晚到结果覆盖。原生取消验证发现禁用整个页面会连同内部取消按钮一起禁用，现改为操作门控并保留区域取消/首页导航可用；关联回归与真实API范围见NOW。

滚轮保护：首页/发现分别记录本次运行已看过的图片ID，随机选择排除已看图并按需读取后续元数据页，复用历史原图但只持有一张已解码源。累计滚轮量并节流，下载中忽略连续滚动，侧栏/详情不切背景。发现选源沿用请求取消/最新版本保护，离页不提交晚到图片。物理鼠标、精密触摸板和不同DPI的感觉仍需体验确认。

验证边界：自生成图片和状态检查不能代替用户图库/真实鼠标与高刷新率设备的主观动画验收；未测量连续帧耗时。本次没有将外部SDK问题报告推定为本项目的确定原因。

本轮布局证据：图库原GridView固定MaxHeight=560导致大窗口图片区域提前截断；已改为剩余高度布局与独立滚动。侧栏蓝框来自IsSelected绘制，已移除常驻着色且保留中性悬停。大/小窗口的底边、滚动到末行及选中发现卡片中性色已纳入原生回归，结果统一见NOW。

缺口：检查使用独立渐变图和模拟长标题，尚不代表用户真实图库、数千图片和所有DPI设置均已验收。参考插画没有加入分发资产。
