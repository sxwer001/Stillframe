# 拾景 · Stillframe v0.1.1 试用版

2026-11-04。Windows x64；合并[桌面恢复修复 #1](https://github.com/sxwer001/Stillframe/pull/1)与[锁屏副本修复 #2](https://github.com/sxwer001/Stillframe/pull/2)。

- 桌面更换前持久保存恢复记录，跨重启可在设置中显式恢复；多屏操作失败时尝试回滚，未完成操作保留记录。
- 恢复前核对系统当前状态，保护用户后续修改；断开显示器、缺失原图或不匹配的全局状态不会被强制覆盖。
- 锁屏使用受登记的独立副本。回收需精确系统读回、至少7天宽限、长度及SHA256校验，保留当前与上一张。取消、拒绝和提交结果不明分别处理；无清单旧文件及内容变化的文件保留。

继续提供自签名MSIX、公开CER、安装脚本、便携ZIP及SHA256。沿用原签名证书、包身份和图库目录；安装步骤见[README](../../README.md#下载与安装)。只公开证书，不提供私钥。

合并后117项核心检查、解压包48项原生UI检查和7项Windows只读诊断通过；MSIX签名及完整载荷、ZIP全部文件校验通过。安装/跨版本升级尚未验证，最终状态以[当前状态](../context/NOW.md#验证状态)为准。真实桌面设置、锁屏替换、热拔插、Windows聚焦/主题模式的完整恢复及其他设备仍待验收。本机锁屏只读探测无法对应文件URI时，会延期回收；不能据此保证现有副本占用已减少。

此版本仍为试用版；未包含本地其他未提交功能，也不修改真实桌面/锁屏来验证发布。
